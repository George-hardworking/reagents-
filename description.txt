agentvs: A python coding file to record the reagents project, this project innovatively questions the efficiency and effectiveness of multi-agent systems. By comparing multi agents systems with single agent systems under rigorous experimental conditions, it captures the precise differences in accuracy among models of the same size when dealing with the same dataset of varying difficulty, and analyzes the differences they have in resource consumption under the same task. This research will set new standards for the application of agents in both practical and academic fields.
